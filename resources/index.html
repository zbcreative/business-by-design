Acceptable Forms of ID

In Colorado, signers must present valid government-issued photo identification. This typically includes a driver's license, state ID, passport, or military ID.

Learn More

Remote Online Notarization (RON)

Colorado allows remote online notarization via secure video call. Learn about the process, requirements, and how to prepare for a RON session.
